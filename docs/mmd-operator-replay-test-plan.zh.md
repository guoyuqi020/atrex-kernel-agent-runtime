**算子真实输入回放：MMD 分布一致性测试方案 v1**

适用对象：FA4、GDN，以及具有相同输入输出契约的其他 reference/candidate 算子。本文是拟议评测协议，尚未接入运行中的评测器，也没有实际 GPU 测试结果。

**1. 测试目标与判定含义**

固定一个真实输入及相关执行上下文，比较 reference 与 candidate 重复运行得到的完整输出分布：

\[
H_0:P(Y\mid x,\mathrm{context})=Q(Y\mid x,\mathrm{context})
\]

使用多带宽高斯核 MMD 和上尾置换检验。无需假设输出服从高斯分布，无需拟合概率密度，也无需预先指定 atol/rtol。高斯核仅定义输出之间的相似度。

结果使用 `NO_DIFFERENCE_DETECTED`、`DIFFERENCE_DETECTED`、`INVALID_TEST` 和 `CONTRACT_FAILURE`。如系统需要 pass/fail，前两项分别映射为“分布筛选通过/不通过”；通过的准确含义是“本次协议下未检出分布变化”，不是已证明同分布或模型效果无变化。

**2. 测试单元与回放集**

一个测试单元由 `input_id + execution_context_id + output_view` 唯一确定。

- 冻结真实输入的数值、dtype、shape、stride、mask、长度、索引、缩放参数及初始 state。不同输入分别检验，不把不同输入的输出混成两个总体。
- 一次完整运行的输出矩阵是一个统计样本。展平时保留元素位置，不把 token、head 或单个元素当作独立运行样本。
- FA4 纳入公开契约要求的最终输出；若返回值与 `out` 是同一个结果，不重复计算同一个检验。
- GDN 纳入输出和传递给后续计算的 state。多输出算子预先声明各字段视图及所有语义输出拼接的联合视图；联合视图用于检查字段之间的依赖关系。纯 scratch、padding 和未定义区域不作为输出，但排除规则必须来自接口契约。
- 联合视图按固定字段次序直接拼接；各字段视图保留，以降低量级差异掩盖局部变化的风险。新增 head/block 等细粒度视图必须在看候选结果之前登记。
- 按实际使用范围覆盖层位置、上下文长度、shape、输入幅值等。manifest 完整列出测试单元，本轮候选的检验总数记为 J。

公开回放集用于开发，另保留冻结的验收输入。候选确定后再运行验收集，避免围绕已公开样本和 p 值反复调整实现。一次候选的统计结论不自动扩展为无限次候选搜索的整体保证。

**3. 默认参数**

| 参数 | v1 配置 | 说明 |
|---|---|---|
| 每个采样组的样本数 | 1000 | 必须是独立运行；可在独立协议版本中预先固定为 500 |
| 采样组 | R_A、R_B、K | 前两组均运行 reference，K 运行 candidate |
| 预热 | 每种实现 20 次 | 编译完成后执行，不计入样本 |
| 距离 | 完整输出的 Frobenius 距离 | 不对每张输出分别缩放、去均值或排序 |
| 带宽基准 | 混合样本非对角距离的中位数 s | 不使用组标签选择带宽 |
| 带宽组合 | s/2、s、2s | 三个高斯核等权平均，作为一个统计量检验 |
| 统计量 | 有偏、非负的经验 MMD²（V-statistic） | 对角项保留；浮点舍入可能产生极小负值 |
| 候选检验族显著性水平 | alpha = 0.01 | 控制同一候选内错误报告分布变化的家族错误率 |
| 多重检验 | Holm | 候选全部 J 项组成一个检验族 |
| R_A/R_B 对照 | 单独组成检验族，alpha_control = 0.01 | 对照用于判定测试有效性 |
| 置换次数 | B = max(9999, ceil(10 J / alpha) - 1) | 运行前按检验族大小确定；对照按自己的族大小计算 |
| 统计计算精度 | FP64 | 输入输出本身保持原 dtype；只在统计阶段转换 |
| 随机种子 | 由固定主种子和测试 ID 派生 | 采样顺序、候选置换、对照置换使用不同子种子并记录 |

B 的规则使 p 值分辨率至少细于最严格 Holm 门槛的十分之一，是工程默认值，不是功效保证。例如 J=30 时 B=29999。J 很大时应先估算置换计算成本，再冻结协议；不能在看到候选结果后降低检验范围或反复追加采样直到通过。

alpha=0.01 表示对确实同分布的检验控制误报风险，不表示“允许 1% 数值误差”，也不表示通过后有 99% 的概率正确。

**4. 采样协议**

对每个冻结输入，构造含 1000 个 R_A、1000 个 R_B、1000 个 K 标签的随机顺序，依次运行。R_A/R_B 调用同一个 reference，只是独立采样标签。一个算子的多个输出视图共用这 3000 次运行，无需按视图重复执行。

每次运行都恢复同一份不可变输入快照和初始 state；清理或重新初始化接口要求的可变输出/工作区。不得把上一轮 GDN 的最终 state 作为下一轮的初始 state。契约允许的输入修改、返回值和 side effect 一并记录。

每次完成后等待设备执行结束，再独立复制输出，避免收集到重复引用、尚未完成的 buffer 或后续被覆盖的内存。输出采样与延迟 benchmark 分开计时。输入和 reference/candidate 源码版本分别记录哈希。

固定 GPU、驱动、编译参数、执行模式、stream 使用规则及可控环境条件。内存地址采用预先登记的策略，例如每次重用各实现的固定 buffer；若测试新地址，则对各组采用相同分配规则，并形成单独的上下文测试。

协议假设各次运行近似独立，并且在同分布原假设下组标签可交换。随机化运行顺序可减少时间漂移与实现标签混淆，但不能自动消除跨运行状态或时间依赖。发现未清理 state、明显漂移或相关性时，结果标记为 INVALID_TEST；需在新协议中采用适当的分块/受限置换，不直接套用全局打乱。

v1 默认每个候选现场采集三组输出。真实输入长期缓存；历史 reference 输出只用于开发分析。未来若复用参考输出，应有单独的环境一致性与新鲜 reference 对照策略，不能把跨环境缓存默认当作可交换样本。

**5. MMD 计算**

对 R_A/K 主检验，令两组各有 n=1000 个完整输出向量，分别记作 r_i、k_i。R_A/R_B 对照采用同样计算流程，但独立选择它自己的无标签带宽。

合并两组样本 Z，计算全部非对角距离 d(a,b)=||a-b||_2。s 为这些距离的中位数，核定义为：

\[
\kappa(a,b)=\frac13\sum_{c\in\{1/2,1,2\}}
\exp\left(-\frac{\|a-b\|_2^2}{2(cs)^2}\right).
\]

核函数的符号使用 kappa，以区别于 candidate 的输出 k_i。

\[
T=\widehat{\mathrm{MMD}}_b^2
=\frac{1}{n^2}\sum_{i,j}\kappa(r_i,r_j)
+\frac{1}{n^2}\sum_{i,j}\kappa(k_i,k_j)
-\frac{2}{n^2}\sum_{i,j}\kappa(r_i,k_j).
\]

这是保留对角项的经验统计量。使用同样统计量置换，不要求它在有限样本下具有零期望；以置换分布作为比较基准。[MMD 方法与统计量来源](https://www.jmlr.org/papers/v13/gretton12a.html)

带宽在每次两样本检验中只计算一次；混合数据及无标签距离在置换后不变，因此置换过程中无需重新选带宽。若更换输入或候选，自动选出的带宽可能不同，不能直接把不同检验的原始 MMD² 排成数值误差排行榜。

退化情况按固定规则处理：

- 所有样本数值完全一致：直接报告 T=0、p=1，标记 `all_outputs_identical`，保留在 J 项检验族中。
- 中位距离为零，但存在正距离：使用严格正距离的中位数；记录 `positive_distance_median`。重复样本保持原频次，不能去重后检验。
- 各组分别恒定，但两组输出不同：按上述规则正常计算。这种确定性差异可以被检出；不能因为没有运行抖动而自动放行。
- 原始输出存在差异、计算出的距离却全部为零，或核矩阵/统计量非有限：按数值计算故障标记 INVALID_TEST，不能进入“完全相同”的捷径。
- 候选出现契约不允许的 NaN/Inf、输出缺失、shape/dtype 不符或非法输入修改：CONTRACT_FAILURE。若 reference 自身违反契约则 INVALID_TEST。契约允许的非有限值需另行定义比较规则，v1 不直接输入高斯核。

**6. 置换与多重检验**

每次从合并的 2n 个样本中随机选 n 个作为第一组，其余作为第二组，计算 T_b。只改变样本所属组，不打乱矩阵内部位置，不交换不同输入的样本。

\[
p=\frac{1+\sum_{b=1}^{B}\mathbf{1}[T_b\ge T_{obs}]}{B+1}.
\]

使用上尾检验和加一修正，不使用双尾 p 值，不把 p=0 当作有效输出。浮点近似相等的统计量应保守地作为并列值处理；记录与验证相应数值比较规则。[置换与 p 值计算参考](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)

对预先声明的 J 个候选检验做 Holm 校正。将 p 值从小到大排列为 p_(1)...p_(J)，校正值为：

\[
\widetilde p_{(i)}=\min\left(1,\max_{j\le i}(J-j+1)p_{(j)}\right).
\]

再还原原始顺序。所有预声明的有效测试都保留；完全相同的项以 p=1 参与。发现无效测试时不删掉它来发布“全部通过”，应将整批标记为不完整/无效。[Holm 实现参考](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)

R_A/R_B 对照单独进行同样的族内校正。对照检出差异时，先报告 INVALID_TEST 并调查；这既可能是环境/采样问题，也可能是检验自身的误报，不能直接推断 reference 有 bug。不能反复重跑直到出现有利结果；重测需要记录原因、废弃范围与新的协议/执行 ID。

**7. 候选级决策**

| 条件 | 结果 | 含义与动作 |
|---|---|---|
| 候选违反接口/非有限值契约 | CONTRACT_FAILURE | 契约不通过，报告具体字段 |
| 采样、统计计算无效，或 reference 对照检出差异 | INVALID_TEST | 本轮不发布有效的整体分布结论 |
| 测试有效，任一候选校正 p <= 0.01 | DIFFERENCE_DETECTED | 分布筛选不通过，定位到具体输入与输出视图 |
| 测试有效，全部候选校正 p > 0.01 | NO_DIFFERENCE_DETECTED | 分布筛选通过 |

报告可同时保留已有契约失败和采样失败，不能用后者覆盖前者。只要任何声明的测试未完成，就不能报告候选“全部通过”。

拒绝同分布只表明分布发生变化，包括候选更稳定、固定偏移等情况；若要接受某种变化，应另行制定可接受变化的协议，不能把当前测试的带宽调到候选通过。原有 atol/rtol 可作为旁路诊断记录，但不参与本方案的 MMD 判定。

**8. 计算与存储实现建议**

输出以原 dtype 分块落盘；统计阶段转换为 FP64。按元素维度分块累加完整样本距离，所有块都计入同一个距离，不能把一个块算作一次独立运行。

小误差叠加在大幅值输出上时，直接用 ||a||²+||b||²-2a·b 容易消减失真。可先给全部样本减去同一个固定向量，再进行 FP64 分块距离计算，并与直接差分抽查对照；不能分别减去各组均值，那会抹掉待检测偏移。

每次两样本检验只构造一次 2000×2000 的 Gram 矩阵，FP64 原始存储约 32 MB，不含输出样本和计算工作区。置换只改变分组权重；用 w_i=1/n 或 -1/n，可计算 T=w^T G w，并将多次置换批量处理。

完整距离计算量约 O((2n)²D)，置换计算量约 O(B(2n)²)，其中 D 是输出元素数。输出采样便宜不等于 MMD 统计计算便宜，预检应分别记录采样、传输、距离矩阵、置换的时间和内存。v1 使用完整输出；如以后采用随机投影、特征近似或删减视图，需作为新协议版本验证，不悄悄替换精确计算。

**9. 报告字段**

每项检验输出：

| 字段 | 内容 |
|---|---|
| 标识 | protocol_version、suite_id、candidate_id、input_id、context_id、output_view |
| 可复现性 | 输入/源码哈希、GPU/驱动/编译信息、dtype/shape/stride、执行与地址策略、所有随机种子 |
| 采样 | 三组样本数、预热次数、运行顺序文件、采样时间、各组数值不同的输出数量 |
| 核参数 | 距离定义、s、带宽列表、权重、零距离回退标记 |
| 统计结果 | mmd2、raw_p、holm_p、B、J、alpha |
| 对照 | control_mmd2、control_raw_p、control_holm_p、control_status |
| 判定 | status、失败或无效原因、未完成测试 |
| 资源 | 采样/统计耗时、输出数据量、峰值内存 |

同时保留采样清单、输入快照引用、输出分块文件、置换种子和原始统计报告。报告不可将 p 值命名为“正确概率”，也不将其作为 kernel 性能排名指标。

**10. 评测器上线前的验证**

先验证测试器，再将它用于真实候选验收：

- 完全一致的常量输出应得到 T=0、p=1；两个不同常量应得到有限、可计算的结果，不产生零带宽故障。
- 用独立同分布的离散、多峰、偏态合成样本测试，不应要求高斯输入。跨重复实验统计误报率及其二项置信区间，不要求每次 reference/reference 都通过。
- 构造均值偏移、缩放、方差变化、少量元素污染，以及同边际但不同相关结构的样本，记录效应大小与检出率。不得声称任意小扰动都必然检出。
- 对含 output/state 的多输出例子验证联合视图；仅各字段边际相同不足以证明联合相同。
- 用小样本枚举全部分组，核对上尾置换逻辑；比较分块距离、Gram 权重计算与直接公式，覆盖 BF16 输出转 FP64 后的微小差异。
- 核对 Holm 实现、并列值、种子复现、缺失样本、输入恢复、输出 buffer 复制和 NaN/Inf 契约。

本文提供的是评测方案；以上为后续实现的验证要求，并非已执行的测试。
