**基于 MMD 的算子输出分布一致性评测：动机与算法**

本文提出一种用于真实输入回放的算子评测方法：在固定输入和执行上下文下，对 reference 与候选 kernel 重复采样，使用多带宽高斯核的最大均值差异（Maximum Mean Discrepancy，MMD）衡量输出分布差异，再通过上尾置换检验作出统计判断。评测目标是判断候选是否改变了参考实现的输出分布。本文给出方法动机、完整算法和需要人工预先规定的参数，不包含代码实现或实验结果。

**研究动机。** GPU 算子优化经常改变并行划分、归约顺序、累加精度或指令组合。由于浮点运算对运算顺序敏感，数学上等价的实现可能产生不同的数值结果；部分实现还会因原子操作或执行调度产生运行间波动。需要区分这两种现象：两个实现使用不同累加顺序，并不意味着每个实现自身都具有随机性。[NVIDIA 浮点计算说明](https://docs.nvidia.com/cuda/archive/12.1.1/floating-point/index.html)

常见的 atol/rtol 判定需要预先选择允许的绝对误差和相对误差。对于不同 dtype、shape、归约长度和输入尺度，统一阈值往往难以确定。余弦相似度可以描述方向变化，但对整体幅度缩放不敏感。更重要的是，用户最终关心的是替换算子是否改变模型行为，而局部数值误差与模型影响之间没有统一对应关系。逐候选运行完整模型又会增加验证成本。

真实输入回放提供了一个成本较低的评测层次：从模型执行中冻结算子输入，之后只运行 reference 和候选算子。对于存在运行间波动的算子，单次输出比较将参考实现自身的随机波动与实现变化混在一起。重复采样后，评测对象可以从“一对输出之间的误差”转为“同一输入下的两套输出分布”。MMD 适合这一问题，因为它能够比较高维样本分布，无需预先指定输出的分布类型或拟合概率密度。[MMD 方法来源](https://www.jmlr.org/papers/v13/gretton12a.html)

这种分布评测与保持模型行为存在明确联系。设固定输入及相关上下文后，reference 和候选的完整语义输出分别为 R、C，后续计算为同一个确定映射 F。如果 R 与 C 同分布，则 F(R) 与 F(C) 也同分布。因此，保持条件输出分布可以作为保持后续行为的一个充分条件。对于带 state 或多个关联输出的算子，这个结论要求比较完整的联合输出，并纳入会影响后续计算的相关状态。

本方法将验收问题表述为“是否能够检出输出分布变化”，从而避免直接人工指定逐元素误差容差。它仍需明确测试范围、显著性水平以及距离和核函数的选择。有限样本未检出差异不构成严格同分布证明；小 MMD 也不自动约束任意后续计算的变化。候选更稳定或存在无害的固定偏移时，同样可能被检出分布不同。这些边界决定了报告中的判定含义。

**问题定义与样本单位。** 给定一个冻结的真实输入 \(x\) 和执行上下文 \(c\)，记 reference 输出分布为 \(P_{x,c}\)，候选输出分布为 \(Q_{x,c}\)。对每个测试单元检验：

\[
H_0:P_{x,c}=Q_{x,c},\qquad H_1:P_{x,c}\ne Q_{x,c}.
\]

分别运行两个算子 \(n\) 次，得到两组样本 \(R=\{R_1,\ldots,R_n\}\)、\(C=\{C_1,\ldots,C_n\}\)。每个样本是一次完整运行的输出，展平时保留所有元素的位置关系。每次运行均恢复相同输入和初始 state，各次采样满足独立性要求，或至少在原假设下满足所采用置换方式的可交换性。

不同输入分别检验，不能把整个回放集的输出混在一起后忽略输入对应关系。例如，候选交换两个输入对应的输出，可能保持总体输出分布，却改变输入到输出的映射。多输出算子以完整联合输出为主测试单元，也可预先添加各字段视图。对于 GDN，联合输出应包含最终输出和传递给后续计算的 state。

**人工需要预先规定的内容。** 下表中的选择在查看候选结果前固定，并在所有候选上遵循同一规则。带宽的绝对数值由样本自动计算。

| 项目 | 需要规定什么 | 本报告采用的起始规则 |
|---|---|---|
| 测试范围 | 回放输入、shape、执行上下文、联合输出及补充字段视图 | 按固定输入分别检验，预先登记全部 J 个测试单元 |
| 每组样本数 n | 每个算子在同一输入下重复运行的次数 | 1000；也可在测试前统一规定为 500 |
| 输出距离 d | 对完整输出采用什么距离，以及是否做固定缩放 | 展平后的欧氏距离，等价于矩阵 Frobenius 距离；不对每个样本单独归一化 |
| 带宽组合及权重 | 相对尺度集合与组合方式 | {s/2,s,2s}，三者等权 |
| 显著性水平 alpha | 本轮检验族允许的同分布误报风险 | 0.01 |
| 置换次数 B | p 值分辨率与统计计算预算 | 按下文给定规则，在测试前由 J 和 alpha 确定 |
| 多重检验规则 | 一个候选的多个测试如何共同判定 | 全部 J 项使用 Holm 校正 |

不需要指定 reference 的分布形式、均值、协方差、概率密度或 atol/rtol。随机种子和采样顺序策略应固定并记录，用于复现。非有限值和输出结构要求继续遵循算子接口契约，未经定义的 NaN/Inf 不输入高斯核。

**算法第一步：计算样本距离并自动选择尺度。** 将两组样本合并为 \(Z=(R_1,\ldots,R_n,C_1,\ldots,C_n)\)，计算所有不同索引的样本距离：

\[
d_{ab}=d(Z_a,Z_b),\qquad 1\le a<b\le2n.
\]

取距离中位数 \(s=\operatorname{median}\{d_{ab}:a<b\}\)。这个过程使用全部混合样本，不使用 reference/candidate 标签挑选带宽。若 s=0 而存在正距离，则使用正距离的中位数；若全部样本数值完全相同，则直接得到 T=0、p=1。重复输出保留原有次数，不能先去重再检验。

**算法第二步：构造多带宽高斯核。** 根据自动得到的尺度 s，构造相似度函数：

\[
\kappa(A,B)=\frac{1}{3}\sum_{q\in\{1/2,1,2\}}
\exp\left(-\frac{d(A,B)^2}{2(qs)^2}\right).
\]

高斯核把距离转换为相似度；其中的带宽是比较尺度，而非 reference 分布的标准差。使用高斯核不要求样本服从高斯分布。多个带宽先组合成一个核，再进行一次检验，避免单一尺度过大或过小导致差异难以体现。该带宽规则是预设的经验选择，不保证对所有差异都有最优检出能力。

**算法第三步：计算观测 MMD²。** 使用保留对角项的经验统计量：

\[
T_{\mathrm{obs}}
=\frac{1}{n^2}\sum_{i,j=1}^{n}\kappa(R_i,R_j)
+\frac{1}{n^2}\sum_{i,j=1}^{n}\kappa(C_i,C_j)
-\frac{2}{n^2}\sum_{i,j=1}^{n}\kappa(R_i,C_j).
\]

该统计量将两组内部的平均相似度与跨组平均相似度作比较。它是有偏的经验 MMD²，在精确计算下非负。对于预先固定的正带宽高斯核及其正权重组合，总体 MMD 为零当且仅当分布相同；有限样本统计量的判定阈值由下一步置换获得，不能直接以 T>0 判定分布不同。

**算法第四步：通过标签置换生成零假设比较基准。** 每次从合并的 2n 个完整样本中均匀随机选取 n 个作为第一组，其余作为第二组，使用相同公式计算统计量 T_b，重复 B 次。样本内容、距离、核函数和自动选择的带宽全部保持不变，只改变组标签。

在原假设及可交换性条件成立时，组标签不应形成特殊分界。置换得到的统计量描述了同分布假设下随机分组所产生的差异。带宽由混合数据以不依赖标签的方式确定，因此各次置换可使用同一带宽。

**算法第五步：计算上尾 p 值。** 较大的 MMD² 支持分布不同，因此采用上尾检验：

\[
p=\frac{1+\sum_{b=1}^{B}\mathbf{1}(T_b\ge T_{\mathrm{obs}})}{B+1}.
\]

分子、分母中的加一采用随机置换检验的保守修正。p 值衡量同分布假设下当前或更大统计量的罕见程度，不是“两个分布相同的概率”。[置换检验与 p 值计算参考](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)

**算法第六步：合并多个测试单元的结果。** 对同一个候选预先登记的 \(J\) 个测试单元，分别计算 \(p_1,\ldots,p_J\)，使用 Holm 方法控制多重检验误报。排序后记为 \(p_{(1)}\le\cdots\le p_{(J)}\)，其校正值为：

\[
\widetilde p_{(i)}=
\min\left\{1,\max_{1\le j\le i}\left[(J-j+1)p_{(j)}\right]\right\}.
\]

全部预声明的有效测试均纳入校正，完全相同的输出以 p=1 参与。任一校正 p 值不大于 alpha，报告“检出分布变化”；全部大于 alpha，报告“未检出分布变化”。若采样、计算无效或测试未完成，则报告“测试无效或不完整”。Holm 控制的是这一检验族内错误拒绝真实同分布假设的风险，不要求各个有效 p 值相互独立。[Holm 校正参考](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)

置换次数需与多重检验门槛匹配。最小可报告 p 值为 1/(B+1)，本报告采用以下预设分辨率规则：

\[
B=\max\left(9999,\left\lceil\frac{10J}{\alpha}\right\rceil-1\right).
\]

这使 p 值分辨率不粗于最严格 Holm 门槛 alpha/J 的十分之一。例如 J=30、alpha=0.01 时，B=29999。系数 10 是工程选择，不是统计功效保证；增加 B 改善置换估计的分辨率，不会增加真实输出样本数 n。

**结论的使用范围。** 本算法为真实输入回放提供了无需人工指定逐元素容差的分布一致性判据。它特别适合比较存在运行间波动的完整输出，并能够反映均值之外的方差及相关结构变化。若两个实现各自完全确定，重复采样只得到两个点质量分布；算法仍可检出差异，但不会因此获得对误差是否可接受的额外解释。

“未检出分布变化”可作为预先约定的分布筛选通过条件；“检出分布变化”表示候选改变了参考输出行为，后续是否接受这种变化需要另行决策。报告应同时给出测试范围、样本数、实际带宽、MMD²、原始及校正 p 值，并保留对应的判定语义。自动带宽因输入或候选而变化时，原始 MMD² 不宜直接跨测试用作误差大小排名。一次候选的误报控制也不等同于无限次自适应候选搜索的整体保证。
